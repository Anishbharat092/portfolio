## 🚀 Overview

This portfolio is designed to showcase production engineering workflows, distributed systems architecture, and clean UI engineering. It features mouse-driven 3D parallax graphics, smooth scroll-linked navigation tracking, and a serverless contact delivery pipeline.

### Key Features

- 💎 **3D Cyber Architecture HUD:** Interactive 3D system status panel with real-time parallax tilt physics.
- 🎯 **Dynamic Scroll Observer Navbar:** Auto-tracking navigation capsule that slides smoothly between sections as you scroll.
- 📩 **Serverless Contact Pipeline:** Integrated API route via `Resend` Node SDK for instant serverless email delivery.
- 🎨 **Dark Mode Glassmorphism:** Custom cosmic theme built with Tailwind CSS, Framer Motion, and Three.js / React Three Fiber.
